School projects, actually running

Coursework from Florida State, 2013–2016, dug out of GitHub and an old Dropbox and put back on a machine where you can use it. Not screenshots — the original code, compiled from the original files, with the original bugs.

Nothing here has been fixed up. Every project is checked out as a frozen git submodule and is never written to; every adjustment needed to make a decade-old program run in 2026 — a compiler flag, a settings shim, a REPL harness, a stand-in for a data file nobody saved — lives outside them. Where something is broken, it is broken the way it was when it was graded, and the pages say so.

Why some of them ask you to sign in

Cloysta is a real shell: it resolves a command against PATH and execvs it, so anyone who opens that page can run whatever the container holds. The MyDS REPL and the 2013–14 console programs are tamer, but they share a pod with the shell. All of them sit behind a second sign-in; the game, the bank, the pages and this one do not.

The shell's container has no credentials, no Kubernetes token, a read-only filesystem and no network access whatsoever — ping and curl resolve nothing and eventually time out. Sessions are capped in both wall-clock and CPU seconds. It is a sealed box with a 2015 shell in it.
