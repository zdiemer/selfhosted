Four school projects, actually running

Coursework from Florida State, 2014–2016, dug out of GitHub and put back on a machine where you can use it. Not screenshots — the original code, compiled from the original commits, with the original bugs.

Nothing here has been fixed up. The four repositories are checked out as frozen git submodules and are never written to; every adjustment needed to make an eleven-year-old program run in 2026 — a compiler flag, a settings shim, a REPL harness — lives outside them. Where something is broken, it is broken the way it was when it was graded, and the pages say so.

  • Cloysta

    C · Operating Systems · Fall 2015

    A Unix shell. Forks, execs, redirects, and has opinions about pipes that turn out not to involve reading what you typed. Runs in a real PTY in your browser.

    Open the shell sign-in

  • Breakout

    Java Swing · Fall 2014

    A complete Breakout with a level editor, save files and an options menu. The original 2014 bytecode, running on a WebAssembly JVM — no plugin, no rewrite, no Java installed.

    Play it

  • pybank

    Django 1.9 · Spring 2016

    An online bank, complete with cleartext PINs and five bare except: pass blocks. Still Python 2.7, because it cannot be anything else.

    Open the bank

  • MyDS

    C++ · January 2015

    A chained hash table, in two header files, with no main() and no README. A REPL reads its private members so you can watch a rehash quietly corrupt its own bookkeeping.

    Open the REPL sign-in

Why two of them ask you to sign in

Cloysta is a real shell: it resolves a command against PATH and execvs it, so anyone who opens that page can run whatever the container holds. The MyDS REPL is tamer, but it shares a pod with the shell. Both sit behind a second sign-in; the game, the bank and this page do not.

The shell's container has no credentials, no Kubernetes token, a read-only filesystem and no network access whatsoever — ping and curl resolve nothing and eventually time out. Sessions are capped in both wall-clock and CPU seconds. It is a sealed box with a 2015 shell in it.
