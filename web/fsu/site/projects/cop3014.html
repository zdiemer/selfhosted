Two of them read files that were never saved

The drink machine opens machine.txt and the grader opens /Users/Zachary/xfile.txt — an absolute path to a 2013 MacBook's home directory, compiled into the binary. Neither data file survives. Both programs here read stand-ins written in 2026, shaped to what the code parses rather than to any assignment text:

  • machine.txt is six drinks, one sold out. The image puts it in the directory the program starts in, because it is opened by relative path.
  • The grader's file sits at exactly /Users/Zachary/xfile.txt inside the container, rather than editing the path out of the source. It has to use bare \r line endings — the old Mac convention — because the program splits on '\r'. The twenty-five students are computing pioneers, so nobody mistakes it for a real class.

Notes, thirteen years on

  • Both Delta Taus and the drink machine loop forever on a letter. cin >> altitude with input that is not a number puts cin into its fail state; every later read then fails without waiting, and the loop's 'Y' never changes. Measured: Delta Tau prints 3 MB of prompts in under two seconds. This terminal pipes each program through a 1 MiB cap, and disables Ctrl-D, which triggers the same thing.
  • The draft says you can escape from 250,000 km. fuel_required = (1 - altitude / 200000) * beam goes negative above 200,000 km, and any fuel at all is more than a negative number. The submitted version catches that case with “Stop being silly! You aren't even close to Delta Tau!”
  • And it crashes at zero metres needing 100.2 kg. Try 1000, 5, 100 in both. The draft prints the crash row's altitude as 0, but computes the fuel requirement from the real one, −400 km. The submitted version clamps the altitude first and shows 100.
  • Declining a drink still takes it out of the machine. Stock is decremented before the “Would you like to make the purchase?” question, and “N” does not put it back. Decline a Grape Soda and the final report shows one fewer.
  • Profit is $0.25 a drink regardless of price — a constant, PROFIT, times the number sold.
  • The grader's histogram never counts a zero. The switch that buckets scores starts at case 1:, so a student who gets nothing right falls through every case. The stand-in data includes one; the “0...5” row says 3 and the rows add up to 24.
  • Project 1's summary comment ends with /. It was meant to be */, so the comment silently continues through the next banner and closes on that banner's own */. It compiles anyway; -Wall notices, in 2026.
  • Projects 3 and 4 both say “PROJECT NUMBER: 1” in their headers. Project 1's header was the template.

The histogram depends on the compiler

The grader draws each bar with setw(n) << cout.fill('*') << cout.fill(' '): two calls that change the stream's state, inside one expression. Before C++17 the language did not say which order those operands are evaluated in. GCC happens to go left to right, and the bars come out right. Built with -fstrong-eval-order=none — the latitude a 2013 compiler actually had, and the header names Visual C++ 2012 — the same source prints this instead. Both were produced by this image's build:
