Show Me A Nole

Android, Summer 2015 — the course was COP 4656, and the apps call it CIS 4930. Two assignments: one survives as a screenshot, the other as three source files and the APK they were built into.

This is the one project on the site that does not run here. There is no way to put a 2015 Android app in a browser tab without rewriting it, and a rewrite is the thing this site does not do. What survives is shown as it is, and the APK is below for anyone with a phone and patience.

Assignment 2: a toggle

One ImageView and one ToggleButton in a RelativeLayout. The layout wires the button straight to a method with android:onClick="onToggleClicked", and that method is the whole of the app's behaviour: 

public void onToggleClicked(View view) {
    boolean on = ((ToggleButton)view).isChecked();
    ImageView img = (ImageView)findViewById(R.id.imageView1);

    if (on) {
        img.setImageResource(R.drawable.gator);
    } else {
        img.setImageResource(R.drawable.nole);
    }
}

Sources: MainActivity.java · activity_main.xml · strings.xml

Notes

  • The package is still com.android.assignment1. Assignment 2 was built by copying Assignment 1's project forward, and the package name came with it. The app's label does say “CIS 4930 - Assignment 2”.
  • It extends ActionBarActivity, which the support library had deprecated in favour of AppCompatActivity in its 22.1 release that April, a few weeks before this was written.
  • The three files are not a buildable project. The layout refers to @dimen/padding_medium and the activity to R.menu.menu_main, and neither resource file was saved. The APK is the only complete build that exists.

Installing it in 2026
Android 14 and later refuse to install anything targeting below API 23. The way round that is from a computer, not the phone: adb install --bypass-low-target-sdk-block app-debug.apk. Older devices and the emulator take it as it is.
