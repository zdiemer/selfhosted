# luke-birthday

Serves [luke.diemer.codes](https://luke.diemer.codes) — a one-off GeoCities-style
30th birthday page for Luke, shipped 2026-08-16.

```
browser ──TLS──▶ Cloudflare edge ──tunnel──▶ infra/cloudflared
                                                   │ https, No TLS Verify
                                                   ▼
                              traefik.kube-system.svc.cluster.local:443
                                                   │ routes by Host header
                                                   ▼
                                     nginx (this chart, site baked in)
```

Also reachable at <https://luke.zachd.duckdns.org>, which rides the DuckDNS
wildcard cert and does not depend on Cloudflare.

## Shape

Like `web/old-diemer-codes`, the chart, the Dockerfile and the source all live
here — but for a simpler reason: the site is four hand-written files and a
folder of generated GIFs. There is **no build step, no npm, and no submodule**.
`site/` is the site.

- `site/index.html` — the page (tables, `<marquee>`, `<blink>`-by-CSS, guestbook)
- `site/geo.css` — the stylesheet
- `site/geo.js` — hit counter, cursor sparkles, snow, guestbook, Risk of Rain 2 sim
- `site/hbd.wav` — a square-wave "Happy Birthday", generated with PIL-adjacent
  arithmetic and Python's `wave` module. Plays on click only; browsers block
  autoplay and that is the one bit of 1998 authenticity we cannot have back.
- `site/img/og.jpg` — the link-preview card, drawn by `gen-og.py` in this
  directory. Regenerate with `python3 gen-og.py` after editing that script; do
  not hand-edit the JPEG. The `og:image` URL carries a `?v=N` — Cloudflare
  caches the card at the edge for a day and scrapers cache it for longer, so
  **bump that N whenever the card changes** or the group chat keeps seeing the
  previous one. The `og:*` tags in `index.html` point at the absolute
  URL, so the preview only resolves once the Cloudflare hostname is live.
- `site/img/baby.gif`, `baby-party.gif` — the dancing babies, drawn by
  `gen-baby.py`. Deliberately not the 1996 Baby Cha-Cha, which is a copyrighted
  Character Studio animation; this is a jointed figure posed per frame. Two
  notes live in that script: GIF's 1-bit alpha needs the transparency index
  reserved by hand, and the pose must depend on `cos(phase)` as well as `sin`
  or the loop mirrors itself and Pillow silently drops the duplicate frames.
- `site/img/` — every GIF, button and badge was generated by a Pillow script;
  the landscape photos are Wikimedia Commons (CC BY / CC BY-SA) and the launch
  photo is NASA (public domain). Credited in the page footer.

## The guestbook is not a database

It writes to the visitor's own `localStorage`, on top of six seeded entries.
There is no backend, and adding one for a page that matters for a day was not
worth a Postgres. The page says so, under the entries.

## Ship a change

```bash
# edit site/…
# bump image.tag in values.yaml AND version/appVersion in Chart.yaml
./build.sh && ./upgrade.sh
```

`imagePullPolicy: IfNotPresent`, so **never reuse a tag** — the nodes will keep
serving the old bytes and nothing will report it.

## One-time setup outside git

1. **GHCR package visibility** — the first `build.sh` push creates
   `ghcr.io/zdiemer/luke-birthday` as a *private* package. Set it to Public, or
   the nodes cannot pull it anonymously and the pods sit in `ImagePullBackOff`.
2. **Cloudflare public hostname** — in Zero Trust → Networks → Tunnels → *the
   tunnel* → Public Hostnames, add `luke.diemer.codes` with origin
   `https://traefik.kube-system.svc.cluster.local:443`, **No TLS Verify on**,
   Host header blank. Same as every row in `infra/cloudflared`'s table. Until
   that exists, the name resolves and Cloudflare 404s.

## Retiring it

It is a birthday page. When it stops being funny:

```bash
helm -n web uninstall luke-birthday
```

then delete the `luke.diemer.codes` Public Hostname in the Cloudflare dashboard
(emptying `ingress.cloudflareHosts` alone leaves the edge accepting the request)
and drop this directory.
